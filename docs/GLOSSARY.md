# MoneyMacros — Glossary

The product rests on one metaphor: **budgeting money the way a nutrition app
plans food.** This table maps each nutrition term to its MoneyMacros meaning. It
is the shared vocabulary for code, UI copy, and docs — prefer these terms.

| Nutrition term | MoneyMacros term | Definition |
|----------------|------------------|------------|
| Calorie budget | Net monthly income | Take-home money available to allocate each month; the total everything is budgeted against. |
| Diet | Budget method | The allocation rule: 50/30/20, 70/20/10, or custom percentages. Chosen at onboarding, changeable later. |
| Macros (protein / carbs / fat) | Needs / Wants / Future | The three top-level buckets income is split into. "Future" = savings, investing, and debt paydown. |
| Micronutrients | Categories | Finer breakdown inside a macro (e.g. Needs → rent, groceries, transport). |
| Logged meal | Expense | A single spend, recorded against one category (and therefore one macro). |
| Recipe | Recurring-expense template | A reusable, scheduled expense (rent, subscriptions) that can be logged in one tap. |
| Calories left today | Safe-to-spend today | Money still available to spend today without breaking the month's plan. |
| Target weight | Goal | A named target amount with a target date (emergency fund, car, deposit). |
| Target date | Goal date | The date a goal is aimed at; the app also shows a *projected* date from current behaviour. |
| Nutri-Score (A–E) | Budget-Score (A–E) | A single grade for plan health (savings rate, needs/wants balance, goal pace). |
| Meal diary | Expense diary | The running log of all expenses for the period. |
| Daily log | Month overview | The current period's totals per macro and category versus plan. |
| Nutrition label | Formula view | The "show the math" panel: the inputs and formula behind any computed number. |
| Meal plan | Plan | The active budget: income + method + goals that spending is measured against. |
| Dietitian consult | Career simulator | Turns an offer's gross salary into real net take-home and shows its effect on the plan and goal dates. |
| Calorie goal by date | Reverse career mode | *(Post-MVP)* The gross salary needed to reach a goal by a chosen date. |
| Sample meal plan | Demo mode | A pre-filled plan (Salma's) that lets anyone explore with no signup. |

## Core money terms (no nutrition metaphor)

| Term | Definition |
|------|------------|
| Gross salary | Pay before taxes and social contributions. |
| Net take-home | Pay after income tax (IR) and social contributions (CNSS / AMO in Morocco). |
| CNSS / AMO | Morocco's social-security and mandatory health contributions, deducted from gross. |
| IR (Impôt sur le Revenu) | Morocco's progressive personal income tax. |
| Savings rate | Share of net income allocated to Future (savings) in a period. |
| Projection | A forward estimate (e.g. net worth over 5 years) from current income, spending, and goals. |
| MAD / EUR | Moroccan dirham / euro — MVP is MAD; EUR comparison is post-MVP. |
